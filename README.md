# RED-2022-30

In questo repository trovate un diff realizzato con l'aiuto dell'IA, confrontando la nuova RED Guide con la precedente versione, datata 2018.

Il confronto si concentra sulle modifiche sostanziali, evidenziando cosa è stato aggiunto, modificato o eliminato, senza considerare le modifiche puramente estetiche.

Così non dovete pasticciare il monitor per cercare di capire cosa è cambiato

Ovviamente, essendo un'analisi fatta con l'IA, prendete il risultato con le dovute cautele e fate sempre riferimento ai documenti ufficiali.

### Diff e contenuti generati con IA

Il confronto tra le due versioni della RED Guide è stato realizzato con il supporto dell'intelligenza artificiale, utilizzando come riferimento la precedente guida del 19 dicembre 2018.

Il diff ha lo scopo di facilitare l'individuazione delle parti **aggiunte, modificate o eliminate**, escludendo per quanto possibile le modifiche puramente estetiche o editoriali.
